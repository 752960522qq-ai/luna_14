# 天空决斗 v12 音效修复说明

已完成音效切片及播放逻辑修改，并生成可覆盖 v11 的 APK。此次更新保留 v11 的飞行、AI、摇杆/瞄准环、预瞄和边界限制功能。

## 问题原因与处理

原开火素材本身包含多次发射；活塞战机及 B-29 还把整段录音作为循环播放，松开开火时不能按单次枪响停止。部分其他武器的音效有全局 220 ms 间隔限制，与实际射速也不一致。

v12 将开火素材裁成单次发射片段，在实际扣除弹药、生成弹道时触发一次。音效间隔按当前武器射速安排，玩家与敌机分别计时；松开开火取消尚未开始的玩家音效，已经发出的单次枪响自然收尾。无弹药不产生新的枪声。MiG-15 或 P-36A 同时发射两组武器时，分别播放对应的短片段。

原喷气发动机录音约 68 秒，整段循环包括声音起落，造成重复“启动—熄火”的感觉。v12 只取中部稳定运行的声音，采用解码后的 PCM 缓冲连续循环；油门变化平滑调整音量和音高，不重启录音。B-29 与活塞发动机也一并处理。暂停、结束和返回主页停止声音，并防止延迟解码在暂停后再次启动。

## 验证结果

- 六种战斗机点射每个选中武器仅产生一次短音效，松开后不再追加录音；弹药耗尽不再触发枪声。
- Bf-109 在 30、60、120 帧/秒下均达到 2 秒内 40 个发射包、80 发弹药消耗，音效数量一致；玩家与敌机相同枪声不会互相抑制。
- B-29 炮塔只在实际发射并扣除弹药时触发，目标超出射程时不播放连射循环。
- 浏览器实际解码九个片段；指针点射只产生一个 F-86 短音效节点；油门变化保持同一个发动机循环节点；暂停/继续/返回主页生命周期通过。
- 浏览器 OfflineAudioContext 连续渲染三个发动机循环周期，无起停静音段；枪声短尾结束后输出为零。WAV 峰值、接缝和分段能量检查通过。
- 完整游戏模块集成检查通过，包括设置切换、摇杆预瞄、出战油门、暂停倒计时、越界自毁及战役豁免；13 个核心飞行/AI/边界/弹道函数与 v11 逐字节一致。
- 签名验证通过（v1/v2/v3），ZIP 对齐与资源校验通过；模型、地图、原生代码等非音频有效载荷保持一致。

验证使用逻辑适配器及 Chromium 原生 Web Audio / WebGL，浏览器动画帧由测试框架控制。未进行 Android 真机安装或主观听感评估。
