# v15：MiG-3、战斗起落架与 5V5

新增 MiG-3，苏联 II 级、权重 2.3、耐久 480。最大/最小航速 640/155 km/h、爬升 15.8 m/s，水平/垂直回转参数为 24/13.2 秒。UBS 机枪 1000 发/分、860 m/s、280 发、伤害 28；双 ShKAS 单管 1800 发/分、820 m/s、合计 1500 发、伤害 15。两种机枪分别计时并同时开火，沿用 I-15 机枪音效及活塞发动机音效。

原上传 GLB 已含标准金属度/粗糙度材质，无必需扩展。保留 68 个材质、61 个贴图材质、23 张嵌入图片及全部原始二进制几何，取消导出时的任意朝向，用统一缩放使机长为 8.25 m，机头 -Z、上方 +Y。添加原模型三片桨叶的旋转节点。`normalize-mig3.py` 可从 `baseline/mig3-upload.glb` 重现输出，原作者 manilov.ap、CC BY 4.0 署名保留于 GLB 和游戏图鉴下方。

MiG-3 战斗实例的主轮分别向内旋转 90°，轮胎和轮毂横置于机翼内侧轮舱；浅整流罩与三段舱门封闭轮舱。尾轮向上、向后收入机身尾部并关闭两片舱门。原始伸展舱门只在战斗克隆中隐藏；图鉴继续显示上传模型的放下姿态。所有变换作用于独立克隆，原模板及图鉴不受影响。`mig3-gear-v15.mjs` 是内嵌生成源。

MiG-3 追尾相机偏移和高度为 2.7 m；MiG-15、F-86、Meteor 与 B-29 均为机尾后 1 m、机体上方 1 m。F3F-2 敌机标记从机型数据读取名称，保留正确的黄色双翼模型。

空域争夺调整为玩家与 4 架我方 AI 对抗 5 架敌方 AI。匹配仍按玩家飞机 BR ±1.0，地图、基地补给、300 m 三维球、15/30 秒占领、积分、无复活及观战规则保持。新增 MiG-3 的匹配池包含 MiG-3、F3F-2、P-36A、Bf-109 B-1，排除相差 1.3 的 I-15bis。

删除战斗内左上角标题，雷达移到左上角。战役和空域信息栏均位于屏幕顶边，数值读数另占一行。空域取消油门缩短覆盖，两个模式统一为上/下各留 25% 的完整滑条。

`npm run check` 覆盖旧机型数值和物理保留、MiG-3 及 F3F-2 弹道/射速、音效、45 个飞行场景、5V5 全机型匹配、占点、补给、击落后观战、无复活与旧战役。`npm run check:browser` 使用实际离线页面、GLTF/Draco、Web Audio 和 WebGL，检查模型比例/方向/贴图、主轮向内与尾轮向后、舱门数量、图鉴源变换不变、五款追尾相机、真实弹丸及 1100×760、844×390、640×360 布局。结果在 `validation/*-v15.json`。未进行 Android 真机安装或触控实测。

原签名交付包由验证的 v14 APK 更新页面与版本号，并加入 MiG-3 模型；65 个原始资源及原生壳文件内容保持不变。包名 `com.luna.skyduel`、versionCode 15、最低 Android 6.0。APK v1/v2/v3 签名及 4 字节对齐均检查，证书与旧包一致。GitHub Actions 可独立执行 Gradle 源码构建，默认 debug 签名与交付签名不同。
